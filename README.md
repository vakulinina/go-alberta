# Go Alberta

## About Go Alberta

Go Alberta is a sophisticated rewards-based crowdfunding platform specifically designed to support and promote Alberta-based businesses. The platform enables local entrepreneurs to showcase their ventures and connect with potential investors.

### Key Features

- **Campaign Management**
  - Create and manage fundraising campaigns with detailed information
  - Multi-step campaign creation process with validation
  - Rich media support including image galleries
  - Customizable perks and rewards system for investors
  - Real-time campaign progress tracking

- **User Features**
  - Secure authentication system
  - Personalized user dashboards
  - Campaign bookmarking functionality
  - Investment tracking and history
  - Profile management with customizable settings

- **Search & Discovery**
  - Advanced category-based filtering
  - Real-time search functionality
  - Responsive campaign cards with dynamic loading

### Technical Stack

- **Frontend Framework**
  - Next.js 15.0
  - React 19.0
  - TypeScript for type-safe development

- **Styling & UI**
  - Tailwind CSS for responsive design
  - Custom component library
  - CSS animations and transitions

- **Development Tools**
  - ESLint & Prettier for code quality
  - Husky for git hooks
  - VS Code recommended extensions setup
  - Conventional Commits standard

### Architecture Highlights

- Clean component architecture with reusable UI elements
- Server-side rendering (SSR) for optimal performance and SEO
- Context-based state management
- Responsive design supporting multiple device sizes
- Modular file structure for scalability

### Development Practices

- Git-flow branching strategy
- Comprehensive documentation
- Automated testing and deployment
- Code quality enforcement through linting and formatting

## Getting Started
First, install packages:

```bash
npm ci
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
